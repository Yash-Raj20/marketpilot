# Product scope

## MVP modules
1. Public landing page and plan comparison.
2. User registration/login and protected dashboard.
3. Market overview and search (demo data until a licensed feed is connected).
4. Personal watchlist persisted per user.
5. Trade journal persisted per user.
6. Responsive mobile API client starter.
7. Database schema for users, watchlists, journal entries, subscriptions and audit events.

## Later phases
- Licensed streaming quotes, corporate actions and exchange data.
- Strategy builder and robust backtesting with fees/slippage/out-of-sample validation.
- Notifications, billing, organization workspaces and broker integrations.
- Regulatory review before personalised advice, research calls or order execution.
